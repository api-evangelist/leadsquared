# LeadSquared

> LeadSquared is a marketing automation and CRM platform for capturing, managing, nurturing and converting leads across sales, marketing and service workflows. The LeadSquared REST API (v2) exposes leads, opportunities, activities, tasks, accounts, users, tickets, lists, products, email campaigns and telephony, authenticated with an `accessKey` + `secretKey` pair issued per admin user. There is no OAuth. The API host is region-specific — using the wrong regional host returns 401.

This file was GENERATED by API Evangelist from https://github.com/api-evangelist/leadsquared (apis.yml + the artifacts in that repo) on 2026-08-13. LeadSquared publishes its own `/llms.txt` at https://www.leadsquared.com/llms.txt; it is a 250KB index of marketing and blog pages and contains no reference to apidocs.leadsquared.com, so it does not help an agent reach the API. It is saved verbatim here as `leadsquared-site-llms.txt`.

## APIs

- [LeadSquared REST API](https://apidocs.leadsquared.com/overview/): Leads, opportunities, activities, tasks, accounts, users, tickets, lists, products, email, telephony, Lapps, Batch Jobs, Webhooks and the Mavis Database. Base `https://api.leadsquared.com/v2` (Singapore) — see the regional host list below.
- [LeadSquared Async API](https://apidocs.leadsquared.com/async-api/): Queued, retrying (up to 10 attempts) variants of Capture Lead, Update Lead, Post Activity, Create Lead & Activity, Capture Opportunity, Update Opportunity and Post Call Log. Returns a `RequestId`; poll the matching status endpoint. Base `https://asyncapi.leadsquared.com/`.
- [LeadSquared Portal API](https://apidocs.leadsquared.com/portal-api/): Self-service portal registration, sign-in, OTP sign-in, password reset and auto-login token generation.
- [LeadSquared Service CRM / Tickets API](https://apidocs.leadsquared.com/service-crm/): Ticket create/update/delete, conversations, attachments, advanced search.

## Conventions

- Versioning: URI path, `/v2`. No version header, no dated versions.
- Pagination: request body objects `Paging {PageIndex, PageSize}` (PageSize max 5000), `Sorting {ColumnName, Direction}` ("1" newest first, "0" oldest first) and `Columns {Include_CSV}`; responses carry `RecordCount` plus the entity array.
- Idempotency: **no** idempotency key. Duplicate prevention is done with upsert-style operations (`Lead.CreateOrUpdate`, `Lead.Capture` with `SearchBy`), not with a client-supplied key.
- Rate limits: plan-based, no `RateLimit-*` / `Retry-After` response headers documented. Pro 10,000 calls/day (+1,000/user/day, cap 250,000) with 10 calls/5s standard and 5 calls/5s bulk; Super 100,000 calls/day (+1,000/user/day, cap 1,000,000) with 20 calls/5s standard and 10 calls/5s bulk.
- Errors: 200 / 400 / 401 / 404 / 500 with the `Status`/`ExceptionType`/`ExceptionMessage` envelope. Not RFC 9457.
- Tracing: the Async API returns a `RequestId` used to poll status; it also requires an `x-api-key` header in addition to the key pair.

## Operations

- [Create a Lead](https://apidocs.leadsquared.com/create-a-lead/) — `POST /LeadManagement.svc/Lead.Create` (`createLead`)
- [Get Lead by Id](https://apidocs.leadsquared.com/get-lead-by-id/) — `GET /LeadManagement.svc/Leads.GetById` (`getLeadById`)
- [Quick Search](https://apidocs.leadsquared.com/quick-search/) — `GET /LeadManagement.svc/Leads.GetByQuickSearch` (`quickSearchLeads`)
- [Post an Activity on a Lead](https://apidocs.leadsquared.com/post-an-activity-to-lead/) — `POST /ProspectActivity.svc/Create` (`postActivity`)

- No `/.well-known/` documents on any LeadSquared host.
- No A2A agent card.
- No official MCP server.
