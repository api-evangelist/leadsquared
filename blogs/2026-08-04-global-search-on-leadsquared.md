1. Feature Overview Global Search provides a unified way to quickly find Leads, Opportunities, Tickets (only on web app), and supported Object Types across the LeadSquared Web and Mobile Apps. Search from a single interface, switch between supported entities without re-entering your keyword, and access relevant record details without navigating away from your current page.
